# 阶段 C 最终报告

版本：`v0.3.0-stage-c`  
完成日期：2026-07-24  
股票范围：固定 30 只 A 股  
最终结论：**工程实现完成，独立性能验收未通过**

## 1. 阶段目标

阶段 C 的目标是在阶段 A 数据管线和阶段 B 统一训练评估框架上，实现并验证动态图与频域融合模型，定位不稳定来源，形成可独立加载的推荐候选，并在候选、基线和规则冻结后执行一次未来 SCREENING。

## 2. 完成内容

### C-1：推荐模型加载与推理闭环

- 实现动态图学习、Gumbel/确定性 Top-k、固定图、单位图、频域传播与多种融合结构。
- 完成无动态图、无频域、固定图、Top-k 和稳定化消融。
- 确认随机 Gumbel 采样、频域传播和可学习融合均存在不同程度的不稳定或性能损失。
- 形成固定控制组集成：`0.5 × 仅时域 + 0.5 × 固定时间图`。
- 三个种子的独立权重加载和 validation 复算误差低于 `1.9e-16`。

### C-2：工程与误差诊断

- 推荐 v2 参数量为 23,010，两个组件检查点合计约 108.7 KB。
- CPU 对 120 个样本推理中位耗时约 0.0315 秒，吞吐量约 3,813 样本/秒。
- 开发期最差五只股票贡献 38.3% 的绝对误差。
- 强上涨与高绝对收益样本是主要开发期风险，预测存在向零收缩。
- 两组件预测相关性低、符号分歧明显，简单平均提供一定稳定收益，但不支持在重复 validation 上继续训练门控器。

### C-3：候选和规则冻结

- 冻结推荐模型结构、0.5/0.5 权重、30 股票范围、价格特征、8 周序列和三个种子。
- 冻结 Naive、FreTS L4、价格版 Minimalist Transformer、仅时域、固定时间图和图频 v1 六组基线。
- 冻结 MAE、RMSE、方向指标、三种子稳定性、尾部误差和股票误差集中度门槛。
- 生成 174 项 SHA-256 清单，根摘要为 `4e0af90936d06f0a16999e86d5c7ff1e70466502175b6c0d52f789a028041c47`。

### C-4：独立 SCREENING

经明确授权，从 BaoStock 获取前复权周线，评分区间为 2023-06-09 至 2024-06-07，共 30 只股票、1,500 个样本。冻结模型和基线在完全相同的样本行上一次性运行，没有重新训练、调权、选种子或修改门槛。

## 3. 技术结论

- 单股票短序列上的随机动态图采样不稳定，不能仅凭结构复杂度获得稳健收益。
- 固定时间图可以作为结构对照，但其频域传播没有形成跨阶段稳定优势。
- 固定等权集成能在开发期改善两个组件，但该收益没有强到足以在未来区间击败 Naive。
- 推荐 v2 的工程闭环、可复现性和方向 F1 有价值，但不能替代独立性能门槛。
- 选择暴露的 validation 优势不能视为泛化证据；一次性 SCREENING 的失败必须被保留。
