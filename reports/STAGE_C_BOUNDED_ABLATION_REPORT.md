## 1. 冻结消融矩阵

本轮没有扩大搜索范围，共运行 6 个预先限定结构，每个结构使用 `20260723`、`20260724`、`20260725` 三个种子：

1. 完整动态图频域门控模型，Top-k=2。
2. 无动态图：单位邻接矩阵。
3. 固定图：自环加前一周的时间邻接。
4. 无频域：仅保留 Transformer 时域分支。
5. Top-k=4：其余保持完整模型设置。
6. 无门控：时域与频域表示等权平均。

共 18 次运行，全部成功完成，无 NaN/Inf 或异常中止。

## 3. 损失来源定位

### 3.1 动态图采样是最稳定的 MAE 损失来源

单位图在三个种子上均降低 MAE，平均改善 6.71%；固定时间图在三个种子上也均降低 MAE，平均改善 8.14%。因此当前 Gumbel-Softmax 动态采样没有学到优于简单结构的稳定关系，是本版最明确、跨种子最一致的问题。

固定时间图比单位图的平均 MAE 再低约 1.54%，但 RMSE 略高且方向 F1 很低，说明局部时间邻接有利于绝对误差，却容易生成偏向单一方向的预测，不能直接作为最终结构锁定。

### 3.2 Top-k=2 过于稀疏，但放宽到 4 只能部分修复

Top-k=4 相对 Top-k=2 平均降低 MAE 3.64%、RMSE 2.73%，说明每个 8 周窗口只保留两条出边会损失信息。不过 Top-k=4 的 MAE 只在两个种子上改善，且仍落后于单位图和固定图，所以问题不只是稀疏度，也包括动态边概率本身的噪声。

### 3.3 频域传播主要增加尾部误差，未体现稳定增益

仅时域结构相对完整模型降低 MAE 6.71%、RMSE 3.44%。进一步在非动态图条件下比较：单位图加频域的 MAE 为 0.036822，仅时域为 0.036821，MAE 几乎相同；但仅时域的 RMSE 比单位图频域结构低约 2.56%，方向 F1 也更高。这表明频域分支不是全部 MAE 损失的唯一来源，但当前复数图传播会放大部分较大误差，并未提供可靠增益。

### 3.4 可学习门控是次要且不稳定的损失来源

等权融合相对可学习门控平均降低 MAE 4.48%、RMSE 1.74%，并取得本轮最高方向 F1。但 MAE 只在两个种子上改善，另一个种子变差，因此门控确有过拟合或不稳定迹象，但证据一致性弱于动态图采样。

## 4. 综合结论

当前性能损失不是由单一模块造成，而是以下组合：

1. 主要问题：Gumbel-Softmax + Top-k=2 动态图采样噪声，跨种子证据最一致。
2. 次要问题：可学习门控会进一步放大种子差异，简单等权融合更稳。
3. 频域问题：对 MAE 的独立影响较小，但会增加 RMSE 和较大预测误差，当前频域图传播没有体现净收益。
4. 稀疏度问题：Top-k=2 确实过窄；Top-k=4 能缓解，但不能解决动态图关系学习质量问题。

工程上最稳妥的下一结构节点是“仅时域 Transformer”作为稳定控制组，同时保留“固定时间图”作为图结构对照。动态图分支不应直接扩大股票池，应先将随机 Gumbel 采样改为更稳定的确定性稀疏化或温度退火，并重新验证三种子一致性。

本轮最低 MAE 的固定时间图仍比 FreTS 4 周高约 2.20%，比价格版 Minimalist Transformer 高约 1.51%；仅优于 Naive 约 1.33%。因此消融定位了问题，但尚未产生优于现有强基线的新候选。
