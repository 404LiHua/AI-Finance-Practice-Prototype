# 项目汇报讲稿

各位老师、同学好，我们团队的实践主题是“AI金融与新质生产力”。本项目围绕金融时间序列预测与风险识别，构建了一个 AI 金融时序预测与风险解释原型系统。

本项目主要解决三个问题：第一，如何整理公开金融时序数据；第二，如何利用 AI 模型进行趋势预测；第三，如何把模型输出转化为普通同学能够理解的风险提示。

在技术路线方面，我们参考了 FreTS、Time-GNN 和 SEP 三类研究。目前原型已经包含样例数据整理、预测结果可视化、风险等级展示和自然语言解释模板。

需要说明的是，本项目不是投资工具，也不提供买卖建议。我们的重点是通过实践让同学理解 AI 金融技术的应用边界、风险意识和新质生产力背景下的数据智能应用方式。
