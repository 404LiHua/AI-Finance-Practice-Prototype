# 项目汇报讲稿

各位老师、同学好，本项目是省级大学生创新项目“基于多模态融合与自适应图学习的金融时序预测模型研究”。项目围绕多模态金融数据、时序预测、自适应图学习、独立评估与风险治理，建设可追溯、可复算、可监控的金融智能系统。

本项目主要解决三个问题：第一，如何整理公开金融时序数据；第二，如何利用 AI 模型进行趋势预测；第三，如何把模型输出转化为普通同学能够理解的风险提示。

在技术路线方面，我们参考 FreTS、Time-GNN 和 SEP 等研究，已经建立统一训练评估、滚动验证、候选冻结、独立加载复算和未来区间评估机制。当前 Stage D 研究门槛已经通过，后续将继续扩大样本和独立区间，并补齐生产服务、安全、监控、审计与合规能力。

项目最终以可商用水准为验收目标，但当前版本仍属于研究验证阶段，不用于自动交易，也不构成投资建议。
