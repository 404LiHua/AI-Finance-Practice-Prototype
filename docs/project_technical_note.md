# 项目技术说明

## 项目名称

基于频域建模、动态图学习与大语言模型解释的金融时序预测原型系统。

## 项目定位

本项目面向省级大学生创新项目和后续产品化，构建“数据治理—模型训练—稳健评估—独立推理—风险解释—生产监控”的金融时序智能系统。研究阶段强调证据可追溯、模型风险治理与独立验证，最终交付以可商用水准为目标。

## 技术来源

- FreTS：频域时间序列预测。
- Time-GNN：动态图时间序列建模。
- SEP：解释性股票预测与风险说明。
- 特征选择综述：支撑均线、波动率、成交量等特征构造。

## 合规说明

当前研究版本尚未完成全部商用验收、合规审批和业务授权，不用于自动交易，也不构成任何投资建议。
