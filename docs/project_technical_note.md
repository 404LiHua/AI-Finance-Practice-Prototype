# 项目技术说明

## 项目名称

基于频域建模、动态图学习与大语言模型解释的金融时序预测原型系统。

## 项目定位

本项目面向高校暑期社会实践和 AI 金融科普场景，构建一个“数据整理-模型预测-结果可视化-风险解释”的展示型原型。项目强调技术理解、风险意识和新质生产力场景认知，不用于真实投资决策。

## 技术来源

- FreTS：频域时间序列预测。
- Time-GNN：动态图时间序列建模。
- SEP：解释性股票预测与风险说明。
- 特征选择综述：支撑均线、波动率、成交量等特征构造。

## 合规说明

本项目仅用于社会实践、技术学习和 AI 金融科普展示，不构成任何投资建议。
