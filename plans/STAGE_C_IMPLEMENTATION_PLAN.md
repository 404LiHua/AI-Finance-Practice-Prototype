# 阶段 C：动态图频核心模型实施计划

计划周期：2026-09-16—2026-11-15
首轮范围：固定 30 只股票、现有周频数据与统一 split
总体目标：实现申报书核心创新——可学习动态图与频域消息传递融合的金融时序预测模型。

## 1. 交付目标

阶段 C 结束时应具备：

1. 可独立运行的动态图频融合模型代码和统一训练入口。
2. 边概率、稀疏邻接、频域图传播、时频融合和预测头的单元测试。
3. 三随机种子的核心模型对比结果和有界消融表。
4. 至少两类动态图可视化：时间依赖图和股票横截面关系图（若采用横截面节点设计）。
5. 参数量、训练耗时、显存/内存和稳定性报告。
6. 技术说明文档，明确模型输入、张量形状、损失函数和失败边界。

## 2. 推荐模型结构

```text
周频多模态窗口
  -> 训练期标准化与模态投影
  -> 时域编码分支（轻量 Transformer/TCN）
  -> 边概率网络
  -> Gumbel-Softmax + Top-k 稀疏邻接
  -> FFT 频域表示
  -> 复数图消息传递
  -> IFFT 重构
  -> 门控时域—频域融合
  -> 下一周收益预测头
```

第一版应控制复杂度：单层时域编码、单层频域图传播、固定最多两种 Top-k，不同时引入
GAN、PPO 或大型语言模型模块。

## 4. 预先限定的消融矩阵

为控制搜索规模，首轮最多安排以下 6 类结构实验：

1. 完整动态图频融合模型。
2. 无动态图：使用单位图或仅自环。
3. 固定图：使用相关系数或时间相邻图。
4. 无频域：只保留时域图传播。
5. 不同 Top-k：建议固定 `k=2` 与 `k=4` 两档。
6. 无门控融合：时域和频域表示直接相加。

如果某一模块出现数值或种子稳定性失败，应先停止该分支并修复结构，不继续扩大超参数搜索。

## 5. 损失函数与稳定性约束

第一版建议：

```text
总损失 = Huber 预测损失
       + λ_sparse × 邻接稀疏惩罚
       + λ_smooth × 相邻窗口图平滑惩罚
       + λ_entropy × 边概率熵约束
```

稳定性检查至少包括：

- 三随机种子 MAE/RMSE 均值与标准差；
- 梯度范数和裁剪次数；
- 邻接密度、孤立节点比例和自环比例；
- 训练过程中 NaN/Inf 检查；
- 完整模型相对 Naive、FreTS 4 周配置和仅价格 Transformer 的比较。

## 7. 阶段验收门槛

阶段 C 只有同时满足以下条件才标记完成：

- 所有核心模块测试通过；
- 主模型三个随机种子均成功运行；
- 完成预先限定的核心消融；
- 输出邻接矩阵和动态图可视化；
- 结果、配置、环境和预测文件可追溯；
- 对失败分支和局限性有明确记录；
- 在 30 股票上稳定后，才讨论扩大股票池。
