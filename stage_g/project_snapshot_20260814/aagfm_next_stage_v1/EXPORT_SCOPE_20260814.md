# AA-GFMNET project snapshot — 2026-08-14

This directory is the public, reproducible-code snapshot of research_tracks/aagfm_next_stage_v1.

Included: 144 text, code, and metadata assets (approximately 596 KB). It contains work-package documents, governance contracts, CPU scripts, local-service source, non-sensitive audit receipts, and aggregate research metrics.

Excluded intentionally:

- raw target, feature, event data and compressed source files;
- FRESH, SCREENING, FINAL, sealed prediction payloads, and shadow prediction tables;
- model weights/artifacts, parquet/npz outputs, and large dry-run materializations;
- Python __pycache__, temporary files, and local environment state.

The exclusion is required by the project's PIT/FRESH custody rules. The original local project package remains the custody location for those assets.

The first published WP12 package remains at the sibling stage_g root; this snapshot preserves the current project structure for subsequent work.
